# E-Commerce Store

A responsive e-commerce website built using React and TypeScript.

## Features

* Product listing
* Product search
* Category filtering
* Shopping cart
* Remove items from cart
* Total price calculation
* Fully responsive design
* Modern dark UI

## Technologies Used

* React
* TypeScript
* CSS3
* Vite

## Installation

```bash
npm install
npm run dev
```

## Future Improvements

* User authentication
* Product images from API
